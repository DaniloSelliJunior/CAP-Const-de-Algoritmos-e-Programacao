# Construção de Algoritmos e Programação (CAP)

Repositório destinado ao armazenamento de exercícios, trabalhos, experimentos e projetos desenvolvidos durante a disciplina de Construção de Algoritmos e Programação.

A disciplina tem como objetivo desenvolver pensamento computacional e algorítmico para a resolução de problemas, além de capacitar os estudantes a implementar soluções utilizando linguagem de programação.

## Conteúdos Abordados

- Fundamentos de Computação
- Lógica de Programação
- Tipos de Dados
- Estruturas Condicionais
- Estruturas de Repetição
- Modularização
- Vetores e Matrizes
- Strings
- Structs
- Ponteiros
- Alocação Dinâmica de Memória
- Manipulação de Arquivos

## Objetivos da Disciplina

- Desenvolver raciocínio lógico e algorítmico
- Modelar soluções computacionais para problemas
- Implementar algoritmos utilizando programação estruturada
- Compreender conceitos fundamentais de organização e manipulação de dados
- Trabalhar com estruturas básicas de dados e memória
